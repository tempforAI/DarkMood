# DARK MOOD：宵鸦岛审判

一款在浏览器中运行的二维像素风**本格推理审判冒险游戏**（原创作品）。

> 1999 年夏，孤岛宵鸦岛。九年前以十二岁之龄破解「白鹭馆事件」的少年侦探·七濑律，收到一封署名为死者的邀请函。
> 十四名客人被困岛上，戴乌鸦面具的「判官」宣告：七只乌鸦将依次坠落。
> 每一起命案的凶手都怀着复仇的理由——而所有的复仇，最终都指向九年前那个夜晚，指向那个「说谎的孩子」。

## 怎么玩

不需要安装，不需要服务器：**直接用浏览器打开 `index.html`** 即可（Chrome / Edge / Firefox / Safari 均可，手机、平板也能玩）。

续作《DARK MOOD Ⅱ：雪葬村审判》见 [tempforAI/DarkMood2](https://github.com/tempforAI/DarkMood2)。

也可以用任意静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 结局

共 8 个结局：6 个坏结局、1 个好结局、1 个真结局。审判中的推理小游戏没有失败，
但关键时刻的**选择**、以及是否找到**可选证据**，会把故事引向不同的结局。
坏结局之后可以「回到分歧点」重新选择；标题画面的「结局一览」会记录已达成的结局，并给出未达成结局的提示。

## 体量

| 部分 | 内容 |
|---|---|
| 序章「鸦啼之岛」 | 登岛、判官的影片、教学审判 |
| 第一章「笼中之鸦」 | 钟声密室 |
| 第二章「镜中之鸦」 | 镜像之翼与双重嫁祸 |
| 第三章「塔上之鸦」 | 飞上塔顶的尸体 |
| 第四章「无面之鸦」 | 灰烬中的名字 |
| 第五章「啄心之鸦」 | 被守了一夜的房间 |
| 终章「审判之鸦」+ 尾声 | 判官的真面目与九年前的真相 |

剧本约 19 万字（约 1.2 万句对白）+ 35 个自由时间事件；共 75 个小游戏、119 件证据。
完整通关约 10～14 小时（视阅读速度）。

## 游戏结构

* **序章 + 五起案件 + 终章 + 尾声**。每章：日常（自由行动、自由时间）→ 命案 → 搜查 → 审判。
* 全部为**本格推理**：解开真相所需的每一条线索都会在审判前呈现给玩家。
* 审判小游戏：证言交锋、一对一对峙、出示证据、指认、灵光拼字、推理回廊、真相重演、投票。
  **没有失败**——答错只会扣除「信念」并逐步给出提示，信念耗尽会自动恢复。设置中可切换「轻松 / 标准」。

## 技术说明

* 纯原生 JavaScript + Canvas 2D，无框架、无构建步骤、无外部资源。
* **所有画面（背景、立绘、小人、图标、地图）都由代码在运行时程序化生成**：高清版在 1920×1080 设计坐标中矢量绘制，
  按输出分辨率（540p～4K）与画质参数生成并缓存；**所有音乐与音效都由 Web Audio 实时合成**。
* 引擎与续作完全共用，作品差异集中在 `js/data/game.js`。
* 性能与兼容：
  * 高清美术按 LRU 字节预算缓存，空闲时根据后续剧本预生成下一张背景与立绘；
  * 只用 ES5 语法与基础 Canvas 2D API，不依赖 WebGL；低画质预设在老手机上也流畅；
  * 文字用 DOM 渲染保持清晰；
  * 只在画面变化或有动画时重绘（dirty flag），只有环境粒子时降为 30fps，标签页隐藏时完全暂停；
  * 背景、审判全景、暗化立绘等全部预生成并缓存；粒子用定长 TypedArray 对象池，每帧零分配；
  * 雨、雾只在室外场景计算与绘制；
  * 章节剧本按需加载（`<script>` 注入，兼容 `file://`），空闲时预加载下一章；
  * 音乐使用单个前瞻调度器，音符节点用完即释放。

### 开发者入口

* `index.html?ch=ch3` 直接从某一章开始；`&label=xxx` 跳到指定标签。
* `node tools/validate.js` 校验所有剧本（标签、证据、小游戏答案、调查点锚点……）。
* `node tools/autoplay.js prologue --all` 用无头浏览器从序章自动玩到结局，报告错误与卡死。
* 结局路线测试：`--be be_silence`（选择通往某个坏结局的选项）、`--thorough`（结束搜查前把调查点再看一遍）、
  `--bond shio=3`（设置羁绊）、`--drop 证据id`（模拟缺少可选证据）。
